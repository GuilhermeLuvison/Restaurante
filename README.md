# Restaurante v1.0

## Introdução

Este repositório, contém um projeto feito na disciplina Programação Orientada a Objetos, do curso Técnico em Informática da Univates.

Através dos meus conhecimentos em Java, POO e o padrão MVC, criei um programa de cadastro de clientes, pratos para cardápio e agendamento de reservas de um restaurante, assim como, opções para listagem de cada cadastrado/registrado, suporte a edição e exclusão dos dados no sistema (sem banco de dados aqui).

Um destaque para este projeto: Este é o primeiro (postado no GitHub) que contém a interface gráfica construída com Java Swing.

Agradecido pela atenção e espero que goste do projeto🎉

## Detalhe importante⚠️

Salve este programa no seu dispositivo local, e o execute com alguma IDE Java.

Pode ser o Apache NetBeans IDE (de preferência, e por conta do Java Swing), Inteliij IDEA ou até mesmo com o VS Code (com extensões Java instaladas).
