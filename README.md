# Restaurante v1.2.1

## Introdução

Este repositório, contém um projeto feito na disciplina Programação Orientada a Objetos, do curso Técnico em Informática da Univates, e que está sendo atualizado com os conhecimentos obtidos na disciplina Programação Avançada.

Através dos meus conhecimentos em Java, Orientação a Objetos, Java Swing e o padrão MVC, criei um programa de cadastro de clientes, pratos para cardápio e agendamento de reservas de um restaurante, assim como, opções para listagem de cada cadastrado/registrado, suporte a edição e exclusão dos dados no sistema.

Um destaque para este projeto: Este é o primeiro (postado no GitHub) que contém a interface gráfica construída com Java Swing.

No momento, AINDA não foi implementado meus conhecimentos em JDBC e PostgreSQL (banco de dados), somente está sendo preparado o terreno e atualizações pequenas com melhorias e correções de bugs.

Agradecido pela atenção e espero que goste do projeto, e do que ele ainda irá se tornar🎉👀

## Detalhe importante⚠️ | Como rodar o programa e requisitos

Salve este programa no seu dispositivo local, e o execute com alguma IDE Java.

Pode ser o Apache NetBeans IDE (de preferência, e por conta do Java Swing), Inteliij IDEA, Eclipse ou até mesmo com o VS Code (com extensões Java instaladas).

A requisição mínima e obrigatória para rodar o programa, além da IDE, é ter o Java 21 instalado na sua máquina.
